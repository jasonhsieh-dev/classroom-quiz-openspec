# 五分鐘 Demo 建議順序

這是目標時程，尚未經真實 Google API 計時驗證。雲端設定、安裝、文件分享、資料備份與完整人工驗收須事先完成。

| 時間 | 展示 |
|---|---|
| 0:00–0:45 | 顯示雲端原文件（兩分頁、公式、合併答案格），貼網址讀取分頁、預覽題目與位置 |
| 0:45–1:20 | 確認 DRAFT、建立兩組，展示活動網址與刷新恢復，開始 OPEN |
| 1:20–2:30 | 兩個隔離學生各答同題；重送相同答案顯示拒絕，另一題真正修改；老師即時監看 |
| 2:30–3:10 | 結束 CLOSED，展示第一名、修改後順位與學生答案隱私 |
| 3:10–4:20 | 寫回預覽、說明共編競態、明確確認，切回真實 Sheets 檢查指定 anchor |
| 4:20–5:00 | 展示未答格、公式、格式、合併及其他分頁保留，刷新成功狀態 |

失敗時如實說明：權限不足檢查 Editor 分享／保護範圍；UNKNOWN 先核對，不直接重送。不要用 Mock 畫面或 XLSX 下載作為真實雲端成功的備援。歷史 XLSX 相容與故障矩陣可在問答時用已標明模式的測試證據補充。
